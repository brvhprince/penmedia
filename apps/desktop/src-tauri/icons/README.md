# Icons

Please add the following icon files for the Tauri app:

- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (for macOS)
- icon.ico (for Windows)

You can use a tool like https://icon.kitchen or create them manually from a source image.

For development, you can temporarily comment out the icon references in tauri.conf.json.
